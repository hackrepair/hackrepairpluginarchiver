Plugins you can't quite delete.

Switching a plugin off leaves it sitting in your list, one click from being switched back on. Deleting it is permanent. Archiving sits in between.

  • Something you are testing

    Put it away between experiments without losing the files.

  • A tool you use twice a year

    Keep it off the Plugins list the rest of the time.

  • A plugin that broke the site

    Make sure nobody clicks Activate on it again, then delete it when you are done.

  • Just not yet

    Not ready to delete, not willing to leave it active. Archive it and decide later.

What it does

An Archive link appears under every plugin, and Archive joins the bulk actions. Plugins › Archived Plugins shows what is in the archive.

  • Archive any plugin in one click, or in bulk
  • Restore one plugin or many, and it comes back configured
  • Download an archived plugin as a zip
  • Delete files from the archive when you are done
  • See when each plugin was archived and for how long, and sort by either
  • Auto-deactivate before archiving, on by default
  • Use several archive folders and choose the active one
  • An activity log of who archived, restored, deleted or downloaded what
  • Export the log as CSV, or clear it
  • Cleans up after itself on uninstall, and leaves your archived plugins alone

Archive, restore, and know what happened

Archiving moves files only. A plugin’s saved settings stay put, so a restored plugin comes back just as you left it.

Respects your lock

When your site turns off file changes, the archive controls step aside. The list stays visible and downloading still works.

It moves files. It does not touch your data.

  • Nothing deleted
  • Settings stay put
  • Folder blocked from the web
  • Nothing sent anywhere

The plugin sends nothing about your site anywhere and adds nothing to the public side of it. Its only network request goes to your own site, an occasional check that the archive folder cannot be read from the web. Nothing is overwritten: archiving or restoring is skipped if a plugin with the same folder name is already at the destination.

It is not a backup tool, a malware scanner or a plugin manager. Archiving takes a plugin out of WordPress’s view, but it does not make a vulnerable plugin safe to keep on disk. If you archive something because it is compromised, delete it when you are done. If you think your site has been hacked, The Hack Repair Guy can help.

Install it in a minute

  1. In WordPress, open Plugins › Add New and search for The Hack Repair Guy’s Plugin Archiver, or use the button below.
  2. Install and activate it.
  3. On Plugins › Installed Plugins, choose Archive under any plugin.
  4. Find it again later under Plugins › Archived Plugins, and restore it when you need it.
