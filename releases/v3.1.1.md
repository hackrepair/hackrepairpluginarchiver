# 3.1.1

Removed all debug logging statements to reduce log clutter in production environments. Debug logs were only active when WP_DEBUG was enabled but were unnecessary for production use.

Published to WordPress.org on September 11, 2025 (SVN tag `3.1.1`). The code-style cleanups in this repository since then (strict comparisons, documented index.php, whitespace) are unreleased and ship in the next version.
