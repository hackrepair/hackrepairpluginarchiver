# 3.3.3

A small release: an Other THRG Plugins guide in the View Details window.

- **Other THRG Plugins.** Plugin Archiver's View Details window now has an Other THRG Plugins tab that introduces seven other tools from The Hack Repair Guy, with a link to each and a note about supporting the project with a donation. The tab is informational: no installs, no outside requests. WordPress.org's own ratings, version and banners are kept.

Validation: PHP syntax lint, shared PHPCS, the plain-PHP logic suites and packaging permissions.
