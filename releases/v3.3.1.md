# 3.3.1

Two small fixes found while testing the upgrade from 3.1.1 on a live site.

- Fix: the Archived Plugins list no longer shows an Archive link on archived plugins. It appeared because the list lives on the settings page, which the screen check did not recognise.
- Fix: the Activity Log now shows the plugin name (and version) when you restore or delete a plugin that was archived before 3.3.0. Those plugins have no saved record, so the name is read from the plugin file.

Validation: PHP syntax lint, shared PHPCS, the plain-PHP logic suites, and the upgrade, restore, archive, download and Secure this archive steps on a live site.
