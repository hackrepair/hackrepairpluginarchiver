# 3.2.0

Security release for the archive folder.

- New archive folders get random names, so the archive cannot be found by guessing. Archives from earlier versions are found automatically; **Secure this archive** (Settings → Plugin Archiver) renames one.
- Every archive folder is blocked from the web (`.htaccess` for Apache 2.2 and 2.4, `web.config`, `index.php`), the rules are rewritten if missing, and the plugin checks them by requesting a marker file from your own site. A warning appears on screen and in Site Health if a folder can be read.
- `DISALLOW_FILE_MODS` is respected: archive, restore and delete are turned off and the lists are read-only.
- Archiving and restoring never overwrite an existing plugin at the destination.
- Only known archives can be selected on the Archived Plugins screen.
- Cleanup: unused commented-out code removed, tab navigation moved out of a nested function and escaped.

Validation: PHP syntax lint, shared PHPCS (new file clean; total findings down from 119 to 112 errors), 33 logic tests, packaging permissions. Not yet run on a live WordPress site.
